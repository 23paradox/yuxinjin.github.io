# Academic homepage

Structural Astro foundation for a long-term academic homepage focused on
Stochastic Control and Games with Imperfect Information.

## Local commands

```sh
pnpm install
pnpm dev
pnpm check
pnpm build
```

## GitHub Pages configuration

The build is static. Set `SITE_URL` and `BASE_PATH` only after the final GitHub
Pages URL and repository name are known. For a project site, `BASE_PATH` should
be the repository path, such as `/repository-name`. For a user site or custom
domain served from the root, leave `BASE_PATH=/`.

Do not add `public/cv.pdf` until the verified public CV is supplied.
